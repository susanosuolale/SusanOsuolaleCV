# Susan Osuolale CV Website 📄

This is a personal CV website built with **C# and ASP.NET Core MVC**.

The website contains multiple pages where visitors can view my experience, education, projects, and contact information. It also includes a tax calculator based on Nigerian tax brackets and a CV download feature that allows visitors to download my PDF CV from the website. and SignalR to provide real-time updates without refreshing the page when the CV file is downloaded.
